================================================================================
                    HEALTHCARE BLOCKCHAIN PROJECT - EXECUTION STEPS
================================================================================

PROJECT OVERVIEW:
==================
This is a Healthcare Blockchain Management System that integrates:
- Flask web application for patient and doctor interfaces
- Ethereum blockchain for secure data management
- MySQL database for data persistence
- Smart contracts for access control and consent management

PROJECT STRUCTURE:
==================
Key Files:
- app.py                    - Main Flask application
- blockchain_utils.py       - Blockchain integration utilities
- db_utils.py              - Database connection and operations
- database_schema.sql      - MySQL database schema
- requirements.txt         - Python dependencies
- init_db.py              - Database initialization
- setup_database.py       - Complete database setup

================================================================================
                            TROUBLESHOOTING
================================================================================

COMMON ISSUES & SOLUTIONS:

1. DATABASE CONNECTION ERROR
   Issue: "Unknown database 'pallavi-3136370892'"
   Solution: Run `python setup_database.py` first
   Check: Verify MySQL server is running

2. BLOCKCHAIN CONNECTION ERROR
   Issue: Web3 connection failed
   Solution: Check internet connection
   Verify: Ethereum network accessibility

3. IMPORT ERRORS
   Issue: ModuleNotFoundError for dependencies
   Solution: Run `pip install -r requirements.txt`
   Verify: All packages installed correctly

4. PORT ALREADY IN USE
   Issue: Port 5001 is occupied
   Solution: Change port in app.py or stop other services
   Alternative: Modify app.run(port=5002) in app.py

5. TEMPLATE NOT FOUND
   Issue: Jinja2 template errors
   Solution: Verify templates folder exists
   Check: All HTML files in templates/ directory

6. STATIC FILES NOT LOADING
   Issue: CSS/JS files not found
   Solution: Verify static folder structure
   Check: File paths in HTML templates

DEBUG MODE:
==========
Enable debug mode in app.py:
```python
app.run(debug=True, port=5001)
```
