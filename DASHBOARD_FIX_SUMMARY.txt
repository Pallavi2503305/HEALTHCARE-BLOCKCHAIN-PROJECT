TECHNICAL DETAILS:
──────────────────

Database Queries Used:

Access Logs:
  SELECT doctor_address, patient_address, resource_id, action, 
         access_timestamp 
  FROM access_logs 
  ORDER BY access_timestamp DESC LIMIT 50

Consents:
  SELECT patient_address, doctor_address, status, timestamp 
  FROM consents 
  ORDER BY timestamp DESC LIMIT 50

Documents:
  SELECT uploader, patient_address, document_name, upload_timestamp 
  FROM documents 
  ORDER BY upload_timestamp DESC LIMIT 50

All merged and sorted by timestamp, top 100 displayed.
